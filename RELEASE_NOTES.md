# MobPsy 1.0.0

Primera versión pública estable de MobPsy.

## Incluye

- Workstation Ubuntu Desktop orientada a OSINT y ciberinteligencia.
- Despliegue reproducible mediante Vagrant + VirtualBox.
- Distribución alternativa mediante OVA preconfigurada.
- Panel público único `MOBPSY.bat`.
- Aplicación gráfica y MobPsy Terminal.
- 25 herramientas y utilidades OSINT organizadas por categorías.
- Firefox, Chromium y Tor Browser con recursos de investigación.
- Sistema de casos, evidencias, exportaciones e historial.
- Integridad mediante SHA-256.
- MobPsy Correlator con exportaciones JSON, CSV, GraphML, HTML, SVG y DOT.
- IA OSINT local mediante Ollama.
- Modelo `mobpsy-osint:latest` basado en Qwen3 1.7B.
- Recuperación de contexto sobre los archivos reales del expediente activo.
- Generación de informes profesionales consolidados.
- Diagnóstico, mantenimiento y actualización desde GitHub Releases.

## Distribución

El código fuente se publica en GitHub. La OVA se distribuye externamente debido a su tamaño y se acompaña de su SHA-256 oficial.
